# UC-heat-analysis
Data analysis of summer heat across all nine UC campuses using Landsat satellite imagery, land-surface temperature, vegetation, and historical geospatial data.

# Overview 
This project examines how landscape, vegetation, and development shape summer heat across the University of California system. Using Landsat satellite imagery and geospatial data, I analyzed land-surface temperature and vegetation patterns across all nine UC campuses.

The analysis was conducted for The Stack at Daily Bruin and contributed to the published article, “How UCLA’s landscape shapes summer heat.”

# Methods
Processed Landsat 9 Collection 2 Level-2 imagery from June and July 2025 across all nine UC campuses
Applied cloud masking using Landsat quality-assurance data to remove contaminated pixels
Calculated land-surface temperature from thermal satellite imagery to compare heat exposure across campuses
Calculated NDVI (Normalized Difference Vegetation Index) using red and near-infrared bands to quantify vegetation coverage
Used spatial campus boundaries to isolate and summarize satellite measurements within each university
Created campus-level summaries to compare land-surface temperature and vegetation patterns across the UC system
Analyzed historical satellite imagery to examine changes in UCLA's landscape and development over time
Combined geospatial analysis with UCLA Housing data to investigate relationships between campus infrastructure, vegetation, and student exposure to summer heat

# Tools
R, GIS, Landsat, Remote Sensing, Javascript, Leaflet, HTML/CSS
